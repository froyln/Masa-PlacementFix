# Masa New Versions Behavior — Minecraft 1.12.2

A LiteLoader companion mod that fixes Tweakeroo block placement around liquids in Minecraft 1.12.2.

## What it does

When Tweakeroo's flexible placement moves a block's target using adjacent or offset mode, this mod moves the click position by the same amount. This brings the placement behavior in line with newer Tweakeroo versions and corrects the reported placement issue around liquids.

The fix has been confirmed in game with the versions listed below. It applies automatically and requires no configuration. Its scope is limited to Tweakeroo placement.

## Requirements

- Minecraft **1.12.2**
- LiteLoader for **1.12.2**
- Tweakeroo **0.31.0**
- MaLiLib **0.54.0**

## Installation

1. Install LiteLoader, Tweakeroo, and MaLiLib for the versions above.
2. Place `Masa-PlacementFix.litemod` in your Minecraft instance's `mods/1.12.2/` folder.
3. Start Minecraft and use Tweakeroo placement as usual.
